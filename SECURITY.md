# Seguridad y datos sensibles

Este repositorio contiene **documentación de investigación y plantillas vacías**. No almacena credenciales ni datos de clientes.

## Política de datos

| Permitido en Git | No permitido en Git |
|------------------|---------------------|
| Estudio y guías | Registros de medición reales |
| Plantillas con datos ficticios | Configuraciones con marcas reales |
| Ejemplos genéricos | Credenciales o tokens |
| Estructura de carpetas | URLs internas o información confidencial |

La carpeta `datos/` está excluida en `.gitignore` precisamente para que tu trabajo local no se publique accidentalmente.

## Si detectas datos sensibles

Si encuentras información que no debería estar en el repositorio:

1. **No** la compartas públicamente
2. Abre un issue privado o contacta a los mantenedores de [seo-as-code](https://github.com/seo-as-code)
3. Indica el archivo y el tipo de dato expuesto

## Reporte de vulnerabilidades

Este proyecto no ejecuta servicios ni procesa datos en servidor. Si detectas un problema de seguridad relacionado con la organización o sus repositorios, repórtalo de forma responsable a través de los canales oficiales de [seo-as-code](https://github.com/seo-as-code).

# Guía de contribución

Gracias por interesarte en mejorar este estudio. Este repositorio es documentación y protocolo de investigación, no código de producción.

## Cómo contribuir

1. Abre un **issue** para proponer cambios al estudio, plantillas o guías
2. Haz un **fork** y envía un **pull request** con cambios concretos
3. Describe el motivo del cambio y qué sección afecta

## Qué tipo de contribuciones encajan

- Correcciones conceptuales o de redacción en el estudio
- Mejoras en plantillas CSV/YAML (sin datos reales)
- Ampliación de ejemplos ficticios
- Traducciones (si mantienen coherencia terminológica)
- Corrección de erratas en la guía de registro

## Qué no aceptar en pull requests

- Datos reales de clientes, marcas o dominios identificables
- Credenciales, tokens, API keys o URLs internas
- Registros de medición completados (`datos/registro_medicion.csv` con datos propios)
- Referencias obligatorias a herramientas comerciales concretas
- Contenido promocional

## Estilo

- Español claro y profesional
- Enfoque en metodología, no en productos
- Ejemplos siempre ficticios (`marca-ejemplo.com`, `competidor-a.com`)
- Mantener la estructura: qué observar → qué hacer → cómo hacerlo
